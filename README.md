Şifre Üreteci

Merhaba! Bu proje, öğrenme sürecimde geliştirdiğim basit bir şifre üreteci uygulamasıdır.

 Ne Yapıyor?

- İstediğin uzunlukta şifre üretir
- Büyük harf, rakam ve sembol seçenekleri sunar
- Aynı anda birden fazla şifre üretebilir

 Nasıl Çalıştırılır?

Bilgisayarında Python yüklü olması yeterli:

    python sifre_ureteci.py

 Kullanılan Teknolojiler

- Python
- random ve string kütüphaneleri

 Notlar

 Backend geliştirme öğrenme sürecimde yaptığım basit bir projedir.
